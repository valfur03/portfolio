## 1. Website hosting (legitimate interest)

Visiting any page on valfur.fr causes your browser to exchange data with the content-delivery network (CDN) operated by **BunnyWay d.o.o.** (bunny.net), Dunajska cesta 165, 1000 Ljubljana, Slovenia (EU).

| Detail           | Value                                                                         |
|------------------|-------------------------------------------------------------------------------|
| Data processed   | IP address (anonymised), requested URL, user agent, timestamp, country code   |
| Legal basis      | Art. 6(1)(f) GDPR — legitimate interest in operating and securing the website |
| Anonymisation    | Bunny.net removes full IP addresses from logs                                 |
| Storage location | European Union                                                                |
| Retention        | 3 days                                                                        |
| Sub-processors   | See [bunny.net sub-processor list](https://bunny.net/gdpr/sub-processors/)    |

No cookies, analytics, or tracking scripts are used on this website.

## 3. Your rights

Under the GDPR you have the right to:

- **Access** your personal data (Art. 15)
- **Rectify** inaccurate data (Art. 16)
- **Erase** your data (Art. 17)
- **Restrict** processing (Art. 18)
- **Data portability** (Art. 20)
- **Object** to processing based on legitimate interest (Art. 21)
- **Lodge a complaint** with a supervisory authority (Art. 77)

To exercise any right, contact the data controller through the contact form.

## 4. International transfers

Both Bunny.net and Strapi Cloud store data within the European Union. If any sub-processor transfers data outside the EU/EEA, Standard Contractual Clauses (SCCs) or equivalent safeguards apply. Refer to each provider's sub-processor list for details.
